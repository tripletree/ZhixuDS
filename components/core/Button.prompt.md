Pill-shaped FabricMind buttons. Primary = bone fill + ink text, glows white on hover; ghost = hairline border; nav = compact pill that tints azure on hover. IconButton = 36px circle (theme toggle).

```jsx
<Button icon="arrow-right">预约演示</Button>
<Button variant="ghost">了解产品</Button>
<Button variant="nav" icon="arrow-up-right" size="sm">预约演示</Button>
<IconButton name="sun" label="切换主题" />
```

CTA copy is a short verb phrase (预约演示 / 了解产品). All buttons are pills — never rectangles.
