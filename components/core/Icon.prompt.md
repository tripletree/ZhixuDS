Lucide linear icon (stroke 1.5–1.75, currentColor) — the only icon system FabricMind uses.

```jsx
<Icon name="sparkles" size={14} style={{color:'var(--color-champagne)'}} />
<Icon name="database" size={20} strokeWidth={1.5} style={{color:'var(--color-azure)'}} />
```

Names: arrow-up-right, moon, sun, arrow-right, sparkles, trending-up, activity, database, box, file-image, layout-dashboard, arrow-up, download, x. Raw SVGs also in `assets/icons/`. Never use emoji or filled icons.
