```jsx
<a style={{display:'flex',alignItems:'center',gap:12}}>
  <BrandMark size={34} />
  <span style={{fontSize:15,fontWeight:500,color:'var(--color-bone)'}}>知序</span>
  <span style={{fontFamily:'var(--font-display)',fontStyle:'italic',fontSize:15,color:'var(--color-bone-soft)'}}>FabricMind</span>

```

The mark's fills are fixed (always dark square) — it does not invert with theme.
