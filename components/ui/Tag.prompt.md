Pill chips (from the AI-chat suggestion chips) and the live ping StatusDot. Tones follow the data palette: neutral for passive labels, azure for the working accent, champagne/rouge sparingly as markers.

```jsx
<Tag>趋势预警</Tag>
<Tag tone="azure" icon="sparkles">AI 洞察</Tag>
<Tag tone="champagne" size="sm">TOP 5</Tag>
<StatusDot label="AI 正在分析" />
```

Chip copy is short (2–4 characters ideal): 趋势预警 / 材料匹配 / 竞品对比. Never emoji — use lucide icons via `icon`.
