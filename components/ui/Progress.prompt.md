Gradient meter row — the 材料机会 TOP 5 pattern: fixed-width label, 6px pill track (bone 6%), azure-deep→azure gradient fill, right-aligned value. Width animates with `--ease-calm`.

```jsx
<Progress label="Lyocell" value={86} />
<Progress label="Recycled Nylon" value={82} />
<Progress label="预算占用" value={64} tone="champagne" />
```

Material names stay in English. Azure is the default; champagne/rouge only when charting a secondary series.
