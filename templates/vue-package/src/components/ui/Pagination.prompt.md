Pill pagination for tables and browse grids: 28px circular buttons, tabular numerals, current page on the bone 8% active-tab treatment, hover tints azure. Ellipsis collapses long ranges; double chevrons jump to first/last. Bind with `v-model:page`.

```vue
<Pagination v-model:page="page" :page-count="24" />
<Pagination v-model:page="p" :page-count="5" :show-ends="false" :siblings="2" />
```

Pair under a `DataTable` or product grid, right-aligned or centered. For year/month steppers (2026 « ‹ › »), use the same chevron IconButtons inline instead.
